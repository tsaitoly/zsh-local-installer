# zsh-local-installer
Tool to user-install zsh

## Dependencies

*   `git`
*   `wget`
*   `curl`
*   `cmake`
*   `pkg-config`

## Usage

You can use this tool both as a root user or as a regular user.

```bash
$ chmod +x zsh-local-installer
$ ./zsh-local-installer
```

Restart your terminal to apply the changes.
